# 南極スライダー 👑🐧🦭

「南極スライダー」は、氷の上をツルツル滑るコマを操って遊ぶ、2人対戦型のブラウザ・ボードゲームです。 ペンギンチームとアザラシチームに分かれて、自分の「王冠」をいち早くゴールへ導きましょう！

## 🧊 ゲームの目的

自分のメインコマ（王冠👑をかぶったコマ）を、盤面中央にある**ゴール（🍧かき氷）**にぴったり止まらせたら勝ちです。

## 🎮 あそびかた

1.  **コマをえらぶ**
    
    *   自分のターンのとき、動かしたい自分のコマをタップ（クリック）して選択します。
        
2.  **すべる（移動する）**
    
    *   スマホ：動かしたい方向へ**スワイプ**します。
        
    *   PC：**矢印キー** または **W/A/S/Dキー** を押します。
        
    *   ⚠️ **注意:** 氷の上なので、**壁や他のコマにぶつかるまで止まれません！**
        
3.  **王冠をゴールへ**
    
    *   他のコマを壁がわりにうまく配置して、王冠コマをゴール（中央）に導きましょう！
        

## ✨ 特徴・機能

*   **クロスプラットフォーム対応:** PCでもスマホでもブラウザだけでサクサク動きます。マウスのドラッグでもスワイプ操作ができます。
    
*   **PWA対応 (アプリとしてインストール可能):** Chromeなどのブラウザから「アプリをインストール」でホーム画面に追加でき、オフラインでも遊べます。
    
*   **レスポンシブなゲーム盤:** スマートフォン（縦・横）、タブレット、PCのどの画面でも、盤面が画面いっぱいに大きく表示されます。
    
*   **リッチなアニメーション:** コマが滑る動きや、ぶつかった時の「むにゅっ」としたバウンドをCSSアニメーションで表現しています。
    
*   **ランダム配置モード (🎲):** いつもの配置に飽きたら、サイコロボタンを押してランダム配置からスタートできます。
    

## 📲 アプリとしてインストールする (PWA)

1.  ChromeなどでゲームのページをHTTPSで開きます。
    
2.  アドレスバー右側の **インストールアイコン**（またはメニューの「アプリをインストール」/「ホーム画面に追加」）を選びます。
    
3.  以降はホーム画面・デスクトップのアイコンから、アプリとして全画面で起動できます。オフラインでもプレイ可能です。
    

## 🛠️ 使用技術

*   **Frontend:** HTML5, CSS3, Vanilla JavaScript
    
*   **PWA:** Web App Manifest + Service Worker (オフラインキャッシュ対応)
    
*   **UI Library:** [SweetAlert2](https://sweetalert2.github.io/ "null") (モーダルダイアログ用・ローカル同梱)
    
*   **Font:** [Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic "null") (Google Fonts)

## 開発者向け

ビルドは不要です。`index.html` をそのまま GitHub Pages（`/Ice_slide-puzzle/`）で配信しています。

```bash
npm ci          # アイコンを作り直すための sharp が入ります
npm run icons   # 元絵を差し替えたときだけ
```

> ⚠️ **リリースするときは `sw.js` の `CACHE_VERSION` を必ず1つ上げてください。**
> 上げ忘れると、児童の端末に古い版が残ったままになります。

ゲーム本体は `app.js` にあります（`index.html` の中に直接書くと、
CSP の `script-src 'self'` で実行されないため切り出しました）。

表示・PWA・アクセシビリティの実測結果は [AUDIT.md](./AUDIT.md) にあります。
